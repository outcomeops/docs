# Features

Once your deploy is live and integrations are connected, four surfaces make up how users actually interact with the platform.

- **[Chat](chat.md)** --- streaming, workspace-scoped conversations grounded in citations.
- **[Workspaces](workspaces.md)** --- team-scoped context bubbles for content + membership.
- **[MCP servers](mcp-servers.md)** --- extend the platform's tool inventory with your own or third-party MCP endpoints.
- **[Code generation](code-generation.md)** --- turn Jira issues or GitHub Issues into PRs.

Start with **Chat** if you're new. It's the primary user-facing surface and the others make more sense once you've watched one query flow end to end.
